# OpenServerOps

A local-first server operations console. The first release is intentionally read-only: choose a server folder, scan it, and get a clear inventory before any future repair or deployment features are added.

## Principles

- No telemetry and no credential collection.
- Read-only checks before any mutating action.
- Clear evidence for every finding.
- Backups and rollback before future writes.
